# Archived legacy YUNTOF static site

> Status: superseded and archived on 2026-07-22.

This repository was the former GitHub Pages/static-site prototype for YUNTOF. It is no longer a deployment source and must not be reactivated for production publishing.

## Current replacement

- Source repository: [`yuntof/g4`](https://github.com/yuntof/g4)
- Source path: `website/`
- Public site: [www.yuntof.com](https://www.yuntof.com)
- Deployment model: release artifact deployed to the production VPS and served by Nginx

The files and commit history in this repository are retained only for historical traceability, including former landing-page and legal-page versions. Current website changes, legal copy, build output, deployment records, and recovery work belong to the replacement repository and its formal PR/review flow.

Do not restore GitHub Pages, the legacy `CNAME`, or a second deployment pipeline from this repository.
